## A few engineering principles I care about

**Make the operating model part of the design.**  
A service is not finished if only its author can recover it.

**Give agents contracts, not vibes.**  
Structured inputs, JSON outputs, and validation beat a clever prompt against an undocumented interface.

**Use AI for uncertainty—not for rules we already understand.**  
Generation and semantic matching benefit from models. Eligibility checks, retries, and publishing gates usually belong in ordinary software.

**Measure the whole workflow.**  
Model output is only one step. Editorial acceptance, latency, cost, failure recovery, and publication all matter.
